# Parking Garage Occupancy Prediction (Original Academic Project)

Academic project developed to predict the occupancy of a large commercial facility parking garage using temporal, meteorological and event-related variables.

The project includes:
- Exploratory Data Analysis
- Correlation Analysis
- Best Subset Selection
- Linear and Non-Linear Modelling

Tools:
- R
- Quarto
- ggplot2
- dplyr

This repository contains the original version of the project.
